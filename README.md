# LangGraph: Zero to Advanced

A hands-on learning journey from Python workflows to production-grade AI agents using LangGraph.

## Why This Repository?

This repository teaches LangGraph through small, runnable examples rather than theory alone. Each lesson introduces a concept, demonstrates it with code, explains the execution flow, and provides exercises to reinforce understanding.

The goal is to build a strong foundation in graph-based workflows and progressively apply it to reliable, observable, and maintainable AI applications.

## Learning Principles

- **Learn by building:** Implement every concept with runnable examples.
- **Understand before advancing:** Verify each lesson before moving forward.
- **Explore failure cases:** Learn common mistakes and debugging techniques.
- **Practice deliberately:** Complete exercises and experiment with variations.
- **Build progressively:** Start with plain Python workflows before introducing LangGraph abstractions.

## Lesson Format

Each lesson aims to include:

1. Learning objectives
2. Concept explanation and analogy
3. Implementation
4. Execution walkthrough and expected output
5. Experiments and exercises
6. Common mistakes and troubleshooting
7. Key takeaways
8. Official documentation references

## Prerequisites

- Python fundamentals
- Basic terminal and Git usage
- Familiarity with functions, dictionaries, and modules

Prior LangGraph experience is not required.
